## รายละเอียดย่อ

Triflex AWS เป็นระบบกันซึม PMMA แบบเสริมใยเต็มพื้นที่สำหรับติดตั้งใต้ Mastic Asphalt เหมาะกับดาดฟ้าอาคารจอดรถ ทางวิ่งรถ และพื้นโครงสร้างที่ต้องรองรับการเคลื่อนไหวสูง จุดเด่นคือกันซึมแบบไร้รอยต่อ แข็งตัวรวดเร็ว ทนความร้อนจากแอสฟัลต์หล่อ ทนต่อสารเคมีและสภาวะด่าง รวมถึงช่วยลดระยะเวลาปิดพื้นที่

ระบบประกอบด้วยชั้นรองพื้น ชั้นกันซึม Triflex ProPark เสริมใย ชั้นป้องกัน และชั้น Mastic Asphalt พร้อมใช้ Triflex ProDetail สำหรับรอยต่อและรายละเอียดต่าง ๆ การติดตั้งจริงควรอ้างอิงเอกสารระบบฉบับล่าสุด และดำเนินงานโดยผู้ติดตั้งที่มีความชำนาญ.

## รายละเอียดผลิตภัณฑ์

## Triflex AWS ระบบกันซึมใต้แอสฟัลต์หล่อสำหรับพื้นดาดฟ้าและอาคารจอดรถ

Triflex AWS คือระบบกันซึมชนิดเหลวแบบเสริมใยเต็มพื้นที่ สำหรับติดตั้งใต้ชั้น Mastic Asphalt หรือแอสฟัลต์หล่อร้อน ระบบผลิตจากเรซิน PMMA ที่แข็งตัวรวดเร็วและทนความร้อน เหมาะสำหรับพื้นดาดฟ้าอาคารจอดรถ พื้นที่สัญจร และโครงสร้างที่ต้องรองรับการเคลื่อนไหวหรือการแตกร้าวสูง ใช้ได้ทั้งงานก่อสร้างใหม่และงานปรับปรุงพื้นเดิม

ระบบจะสร้างชั้นกันซึมต่อเนื่องบนพื้นผิว รวมถึงบริเวณรอยต่อ มุม ขอบพื้น และรายละเอียดที่มีรูปทรงซับซ้อน เมื่อทำงานร่วมกับชั้นแอสฟัลต์หล่อ จะช่วยแยกหน้าที่อย่างชัดเจน โดย Triflex AWS ทำหน้าที่ป้องกันน้ำ ส่วนชั้นแอสฟัลต์ด้านบนทำหน้าที่เป็นชั้นรับน้ำหนักและรับการสัญจรเป็นหลัก

### จุดเด่นของ Triflex AWS

- เป็นระบบกันซึมแบบเสริมใยเต็มพื้นที่ ช่วยเพิ่มความแข็งแรงและรองรับการเคลื่อนไหวของโครงสร้าง
- ใช้เรซิน PMMA ที่แข็งตัวรวดเร็ว ช่วยลดระยะเวลาการติดตั้งและระยะเวลาปิดพื้นที่
- สามารถปูชั้น Mastic Asphalt ทับได้หลังติดตั้งชั้นกันซึมประมาณ 3 ชั่วโมง
- ป้องกันน้ำบริเวณพื้นผิว รอยต่อ และรายละเอียดต่าง ๆ ได้แบบต่อเนื่องไร้รอยต่อ
- ไม่จำเป็นต้องใช้แผ่นโลหะปิดรอยต่อแบบกลไกในบริเวณจุดเชื่อมต่อตามระบบที่ผู้ผลิตกำหนด
- มีความทนทานต่อแรงทางกลและสารเคมี
- ทนต่อการไฮโดรไลซิสและสภาวะด่าง
- ยึดติดกับพื้นผิวเต็มพื้นที่ ช่วยลดโอกาสที่น้ำจะไหลแทรกอยู่ใต้ชั้นกันซึม
- เมื่อตรวจพบความเสียหาย สามารถระบุตำแหน่งและซ่อมแซมได้ง่ายกว่าระบบที่น้ำสามารถไหลกระจายใต้ชั้นวัสดุ

#### Triflex AWS เหมาะสำหรับพื้นที่ใด

Triflex AWS เหมาะสำหรับพื้นที่ที่ต้องใช้แอสฟัลต์หล่อเป็นชั้นรับน้ำหนัก แต่ยังต้องมีระบบกันซึมที่สามารถรองรับการแตกร้าวและการเคลื่อนไหวของโครงสร้างได้ เช่น

- ดาดฟ้าอาคารจอดรถ
- พื้นจอดรถที่เปิดรับสภาพอากาศ
- ทางวิ่งรถและพื้นที่สัญจรบนโครงสร้าง
- พื้นเหนือพื้นที่ใช้งานภายในอาคาร
- พื้นที่ที่ต้องปู Mastic Asphalt เป็นชั้นรับการสัญจร
- โครงสร้างที่มีโอกาสเกิดการเคลื่อนไหวหรือรอยแตกร้าว
- งานปรับปรุงระบบกันซึมเดิม
- งานก่อสร้างใหม่ที่ต้องการระบบกันซึมใต้แอสฟัลต์หล่อ

#### โครงสร้างระบบ Triflex AWS

##### 1. ชั้นรองพื้น

ชนิดของไพรเมอร์ต้องเลือกให้เหมาะกับวัสดุพื้นผิว โดยระบบมีตัวเลือกหลายประเภท เช่น

- **Triflex Cryl Primer 222** สำหรับพื้นผิวแอสฟัลต์ ปริมาณการใช้ขั้นต่ำประมาณ 0.40 กิโลกรัมต่อตารางเมตร
- **Triflex Cryl Primer 287** สำหรับพื้นผิวดูดซึม เช่น คอนกรีต ปูนปรับระดับ หรือไม้ ปริมาณการใช้ขั้นต่ำประมาณ 0.35 กิโลกรัมต่อตารางเมตร
- **Triflex Metal Primer** สำหรับโลหะและพื้นผิวที่มีสนิม ปริมาณการใช้ประมาณ 0.15 ลิตรต่อตารางเมตร
- **Triflex Glass Primer** สำหรับพื้นผิวกระจกที่ไม่ผ่านการขัด ปริมาณการใช้ประมาณ 0.05 ลิตรต่อตารางเมตร
- **Triflex Pox Primer 116+** สำหรับรองพื้น อุดผิว และปรับระดับความขรุขระในระบบที่เหมาะสม ปริมาณการใช้ประมาณ 0.30–0.40 กิโลกรัมต่อตารางเมตร

ค่าการใช้งานดังกล่าวอ้างอิงพื้นผิวเรียบและสม่ำเสมอ ปริมาณจริงอาจเพิ่มขึ้นตามความหยาบและสภาพหน้างาน

##### 2. ชั้นกันซึมเสริมใย

ชั้นกันซึมหลักใช้ **Triflex ProPark** ร่วมกับ **Triflex Special Fleece** โดยแผ่นใยทำหน้าที่เสริมความแข็งแรงและช่วยควบคุมความหนาของชั้นวัสดุ

ปริมาณการใช้ Triflex ProPark ขั้นต่ำอยู่ที่ประมาณ 3 กิโลกรัมต่อตารางเมตรบนพื้นผิวเรียบ ชั้นนี้ทำหน้าที่เป็นระบบกันซึมต่อเนื่องและช่วยรองรับการเคลื่อนไหวหรือรอยแตกร้าวของพื้น

##### 3. ชั้นป้องกันระบบกันซึม

เหนือชั้นกันซึมจะมีชั้นป้องกันที่ใช้ Triflex ProPark และทรายควอตซ์ขนาดประมาณ 0.7–1.2 มิลลิเมตร เพื่อเตรียมพื้นผิวให้เหมาะกับการปูแอสฟัลต์หล่อร้อนด้านบน

เอกสารระบบระบุปริมาณ Triflex ProPark สำหรับชั้นป้องกันขั้นต่ำประมาณ 3 กิโลกรัมต่อตารางเมตรบนพื้นผิวเรียบ ส่วนรายละเอียดปริมาณทรายและวิธีโรยต้องอ้างอิงเอกสารวางแผนของระบบ

##### 4. ชั้น Mastic Asphalt

ชั้นบนสุดเป็น Mastic Asphalt หรือแอสฟัลต์หล่อร้อน ทำหน้าที่เป็นชั้นรับน้ำหนัก รับแรงจากการสัญจร และปกป้องชั้นกันซึมด้านล่าง

โครงสร้างของ Triflex AWS ทำให้สามารถออกแบบให้ชั้นแอสฟัลต์ทำหน้าที่รับน้ำหนักโดยเฉพาะ ขณะที่ประสิทธิภาพด้านการกันซึมจะอยู่ที่ระบบ PMMA เสริมใยด้านล่าง

#### การทำรายละเอียดและรอยต่อ

บริเวณมุม ขอบพื้น รอยต่อ ท่อระบายน้ำ จุดทะลุ และจุดเชื่อมต่อแนวตั้ง ใช้ **Triflex ProDetail** ร่วมกับ Triflex Special Fleece เพื่อให้ชั้นกันซึมเชื่อมต่อกับพื้นหลักอย่างต่อเนื่อง

Triflex ProDetail ผลิตเป็นวัสดุที่มีความข้นเหมาะกับงานแนวตั้ง ช่วยลดการไหลย้อยระหว่างติดตั้ง และมีปริมาณการใช้ขั้นต่ำประมาณ 3 กิโลกรัมต่อตารางเมตรบนพื้นผิวเรียบ

#### ติดตั้งรวดเร็วและลดเวลาปิดพื้นที่

จุดเด่นสำคัญของ Triflex AWS คือระยะเวลาการทำงานที่รวดเร็ว ไพรเมอร์บนพื้นผิวแร่บางประเภทสามารถเคลือบทับได้หลังประมาณ 45 นาที และสามารถติดตั้งแอสฟัลต์หล่อร้อนบนชั้นกันซึมได้หลังประมาณ 3 ชั่วโมง เมื่ออุณหภูมิและสภาพหน้างานเป็นไปตามข้อกำหนดของผู้ผลิต

คุณสมบัตินี้เหมาะกับอาคารจอดรถหรือพื้นที่สัญจรที่ไม่สามารถปิดใช้งานเป็นเวลานาน และช่วยให้ผู้รับเหมาสามารถแบ่งพื้นที่ทำงานเป็นช่วง ๆ เพื่อลดผลกระทบต่อการใช้งานอาคาร

#### ความทนทานต่อความร้อนและมาตรฐาน

ผู้ผลิตระบุว่า Triflex ProDetail ซึ่งใช้สำหรับรายละเอียดภายในระบบ ผ่านการรับรอง European Technical Approval และมีเครื่องหมาย CE นอกจากนี้ ระบบยังผ่านการทดสอบความทนความร้อนจากการปู Mastic Asphalt ที่อุณหภูมิสูงถึงประมาณ 250 องศาเซลเซียส และผ่านการรับรองความต้านทานรากพืชตามแนวทางการทดสอบ FLL

#### การเตรียมพื้นผิวก่อนติดตั้ง

พื้นผิวต้องแข็งแรง สะอาด แห้ง และปราศจากฝุ่น น้ำมัน จาระบี ชั้นเคลือบที่หลุดร่อน หรือสิ่งปนเปื้อนที่อาจลดการยึดเกาะ ควรตรวจสอบความแข็งแรงของพื้น ความชื้น รอยแตกร้าว ความลาดเอียง และระบบระบายน้ำก่อนเริ่มติดตั้ง

ชนิดไพรเมอร์ รายละเอียดการเสริมใย ความหนาของระบบ และโครงสร้างชั้นแอสฟัลต์ต้องกำหนดตามวัสดุพื้นผิว ระดับการรับน้ำหนัก และข้อกำหนดของแต่ละโครงการ
